Recovery phone number

Sign-in codes

When you sign in on a new device, Verilume sends a 6-digit code. It goes to your email unless you turn on text codes. Text codes use the phone number above, so save it first. Only you can change this, for your own profile.

Communication permissions

Choose how Verilume can reach you. These apply to this account's primary contact — team members set their own preferences when they accept an invite.

Payment methods

A credit card on file is required to use self-service billing. ACH bank transfer is available as an additional method once a card is on file. Prototype note: no real payment processor (Stripe, Braintree, etc.) is integrated — this only stores the last 4 digits in this session, the same way a real integration would never store a full card or account number client-side.

Invoices & financial tracking

Every invoice issued to this account, tracked for real in this build's backend. Prototype note: downloads are still mocked — no real PDFs are generated, and no payment processor is connected — marking an invoice Paid just records that fact, it doesn't move any money.

In the live build: contact info, communication preferences, and team member/role records write to a new Sheets tab scoped to this account's Client ID (same isolation model as Deliverable 15); password changes route through a real auth provider (none chosen yet); credit card and ACH details are tokenized by a real payment processor (Stripe/Braintree — not chosen yet) and only a token + last-4 are ever stored, never a full card or account number; and invoices are generated by whatever billing system issues them, not by this page.
