Rules for both
  • No PR approval ever waits on a search score, and Search Everywhere never edits or publishes a release.
  • Both sides read the same Train the Brain keyword list, negative list and approved facts. Neither keeps a private copy.
  • Release topics from priorities count as suggestions only. The five-item priority limit is unchanged.
  • Build status: the optimize step and keyword module are built; both hand-offs are now built (2026-10-05), except release dates on the Search Console charts. Impressions on the strip come from the latest Pages file, not a count since publishing.
