Team Console

The staff side of the platform. One sign-in for the Verilume team to find clients, change levels, open a client's workspace, review AI output, manage the team and read the documentation Library. It replaced the separate Ops Console in release r114. Belongs to Data Management › Registration & Account Management (staff access) and Company Profile & Team (client rosters).

Owner Todd BrownSystem frontend/platform.html, backend/ops-console-app.html, backend/server.js (/api/platform/*), backend/platform-docs/Verified against working tree and a scratch server, 2026-11-25 (builds r114, r115)Status Built; tested on a scratch server and in a headless browser. Not yet run on live Postgres, Railway or Twilio.

Sign-in§ 01

1

Email and password

At /platform. Wrong passwords pause sign-in (10 for a name or 40 from a network in 15 minutes).

2

6-digit code by email or text

Text needs a verified mobile number saved under My mobile and uses the same Twilio Verify service as the client portal; no separate key. Without Twilio the text button says so and email still works.

POST /api/platform/login
3

Session

12 hours. "View as" a client lasts 4 hours and is logged. Password reset is email only.

Documentation Library§ 04

The Library tab lists every document by category (Start here, Product, Training, Security, Database) with search, an in-page reader, print or save as PDF, and downloads for PDF and Word files. The backend serves it from backend/platform-docs (a manifest.json plus one HTML file per document and a files folder). It is not on the public site. Links between Product docs open inside the Library. To add a document, add the file and one manifest line and deploy the backend.

EndpointPurpose
GET /api/platform/docsThe manifest
GET /api/platform/docs/:idOne HTML document
GET /api/platform/docs/file/:nameOne listed PDF or Word file

Known gaps & open items§ 06 — for product awareness

Roles are not separated beyond Read-only

A team sign-in unlocks every staff route, including ones that used to need the secret admin token (for example AI review writes). A role check per route is the fix.

Not run on live infrastructure

Verified on a scratch server and headless browser. Not run on Postgres, Railway or Twilio. Postgres lowercases some column names; the new routes read them through a helper, so check the first live open of an account.

No create or archive account in workspaces

Those exist elsewhere in the Team Console for Owner and IT.

Premium commitment tier not recorded

Flex, Quarterly and Annual need a pricing decision first.

Library files must ship with the backend

The platform-docs folder must be in the deploy bundle. If it is missing, the Library says so rather than showing an empty list.
