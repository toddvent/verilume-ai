How to add a document

  1. Write the page as HTML (or save a PDF or Word file).
  2. Put it in the server's platform-docs folder and add one line to manifest.json: id, title, category (Product, Training, Security or Database), summary, audience, updated date.
  3. Deploy the backend. It appears in the library for signed-in team members. Nothing is published to the public site.

Update a document in place and change its date; do not create dated copies. After each workstream, update the matching Product doc and its Decision Log.
