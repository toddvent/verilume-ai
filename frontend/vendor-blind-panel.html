Vendor Blind Panel

Fires one shared prompt at all five licensed vendors (Anthropic, OpenAI, Gemini, Grok, Perplexity) through the app's own already-configured keys, and shows every result blind-labeled — Option 1 through 5, randomized order — so you can judge the writing before knowing who wrote it. Built for one exercise: comparing candidate copy for the Free Assessment results panel rework. Nothing here is saved or scored.

Cost note: every run calls all five providers for real. Only run this when you actually want a fresh comparison.

Inputs

Matches the real free-assessment results-panel feature's actual inputs — same prompt-builder, not a separate invented one. Prefilled with real Atlas Ocean Voyages data where it's actually known; blank fields are blank because that data was never captured this session, not guessed.

Results — blind

Randomized order, no vendor name shown by default. Reveal a single card or all at once.
