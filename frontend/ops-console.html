Reference Data Staff only

The Population Index and DMA roll-up every account's Match Market Builder results depend on need two shared reference files no client supplies: population by zip (U.S. Census, free) and a zip→DMA crosswalk (DMA boundaries are Nielsen's; the free crosswalk is a public approximation, labelled that way wherever a DMA appears — a licensed Nielsen file can be loaded below and replaces it). Zip centroids (for store trade areas) are the same kind of one-time, shared load. None of this is account-scoped — one load here serves every account.

Click "Check status" to load current counts.

2020 Census ZCTA population + public zip→DMA crosswalk, fetched server-side through this console's own session and saved to the backend in batches. Needs a Census API key configured as the CENSUS_API_KEY environment variable on the backend — if that's missing, this will say so directly.

Demographics: 2022 ACS 5-Year age (5 generations: Gen Z, Millennials, Gen X, Boomers, Silent Gen — the same ones Company Profile's generation picker can actually back with real Census data) and real per-bracket household income counts, by zip — feeds the Match Market Builder's per-store trade-area Audience/Wealth Fit scoring and the Test/Control demographic matching dimension. Same Census API key requirement as above. Pulled per state (50 states + DC + Puerto Rico) and merged — a prior version pulled the whole country in one flat query, which Census's ZCTA geography doesn't support reliably and silently returned only 2.7% of zips nationally. Use "Test these states" with a couple of sample states first to confirm real per-zip coverage before running the full national reload, which takes noticeably longer (dozens of Census API calls).

IRS top-bracket income: real per-zip average income for households earning $200,000+ (IRS Statistics of Income, ZIP Code Data — irs.gov, free, no API key, one national file). Census's own income table can't tell a $225,000-average area apart from a $2,000,000-average one — both land in the same open-ended top bracket — so this fills in the one number Census can't provide, letting genuinely wealthy areas score as such. Independent of the Census demographics load above; run both for the most accurate Wealth Index.
